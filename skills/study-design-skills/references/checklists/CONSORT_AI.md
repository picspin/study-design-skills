# CONSORT-AI Extension Checklist

| # | Item | Reported on page |
|---|------|------------------|
| 1 | Specify the type of AI intervention (e.g., deep learning, logistic regression) | |
| 2 | Describe the AI intervention development, including training details, preprocessing, and model selection | |
| 3 | Specify the intended use of the AI intervention in the clinical pathway | |
| 4 | Describe the handling of input data quality and missingness | |
| 5 | State the output of the AI intervention (e.g., classification, probability, segmentation) | |
| 6 | Describe how the AI intervention was integrated into the clinical workflow | |
| 7 | Report the skills/expertise required for clinicians interacting with the AI | |
| 8 | Describe how and when the AI intervention output was made available to clinicians | |
| 9 | Describe the human-AI interaction evaluation (clinician review, override, time to decision) | |
| 10 | Report device-to-device variability if AI is deployed across multiple devices or sites | |
| 11 | Describe the dataset used for training, validation, and testing of the AI component | |
| 12 | Report measures of AI performance (accuracy, sensitivity, specificity, etc.) in the trial context | |
