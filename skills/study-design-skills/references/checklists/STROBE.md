# STROBE Checklist

| # | Section | Item | Reported on page |
|---|---------|------|------------------|
| 1 | Title/Abstract | (a) Indicate study design in title/abstract; (b) structured abstract | |
| 2 | Introduction | Scientific background and rationale | |
| 3 | Introduction | Specific objectives, including any prespecified hypotheses | |
| 4 | Methods | Study design — key elements presented early | |
| 5 | Methods | Setting, locations, relevant dates (recruitment, exposure, follow-up) | |
| 6 | Methods | (a) Eligibility criteria; (b) sources and methods of selection; (c) matching criteria | |
| 7 | Methods | Clearly define all outcomes, exposures, predictors, confounders, effect modifiers — give diagnostic criteria | |
| 8 | Methods | For each variable of interest, give sources of data and assessment methods | |
| 9 | Methods | Describe any efforts to address potential sources of bias | |
| 10 | Methods | Explain how study size was arrived at | |
| 11 | Methods | Explain how quantitative variables were handled in analyses | |
| 12 | Methods | (a) Statistical methods; (b) subgroup; (c) missing data; (d) matching; (e) sensitivity | |
| 13 | Results | Number of individuals at each stage (eligible, confirmed, included, followed up, analysed) | |
| 14 | Results | Give characteristics of participants (Table 1) | |
| 15 | Results | Indicate number of participants with missing data for each variable | |
| 16 | Results | Report unadjusted and adjusted estimates, precision, confounder specification | |
| 17 | Results | Report other analyses (subgroups, interactions, sensitivity) | |
| 18 | Discussion | Summarise key results with reference to study objectives | |
| 19 | Discussion | Discuss limitations, bias, imprecision, and generalisability | |
| 20 | Discussion | Give cautious overall interpretation considering objectives, limitations, and evidence | |
| 21 | Discussion | Discuss external validity | |
| 22 | Other | Source of funding and role of funders | |
